# BUNKED. — Skip Smart. Stay Safe.

A student attendance calculator developed in two versions.

## Releases
- **v1.0.0** — Original standalone HTML/CSS/JavaScript calculator.
- **v2.0.0** — Final full-stack attendance control room, visually aligned with the supplied `white blue.html` reference. Includes Flask, SQLite, multi-subject tracking, configurable target, class logging, history, forecast, and C++ calculation engine.

## Run V2
```bash
cd v2
python -m pip install -r requirements.txt
python app.py
```
Open http://127.0.0.1:5000.

## Version history
`v1.0.0` and `v2.0.0` are Git release tags. `main` contains the latest V2 code.
